# World Diary

A personal travel blog and visual journal built with **HTML5** and **CSS3**.  
This project brings together my travel experiences across different European countries through curated city pages, photography, short notes, and selected media content.

## Overview

**World Diary** is a static front-end project designed as a personal travel archive.  
It presents countries and cities I have visited in a structured and visually engaging format. Each section is intended to reflect not only locations, but also atmosphere, architecture, and personal impressions.

The project focuses on:
- clean navigation
- visual storytelling
- organized country-based content
- responsive and modern presentation

## Features

- Dedicated pages for multiple countries
- City-focused travel notes
- Image-based visual presentation
- Embedded video content
- Responsive layout for different screen sizes
- Centralized styling with a shared CSS file

## Tech Stack

- **HTML5**
- **CSS3**

## Run Locally

1. Clone the repository:
```bash
git clone https://github.com/zeynepg22/world-diary.git
```

2. Go to the project folder:
```bash
cd world-diary
```

3. Open index.html in your browser.
